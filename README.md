# Escape Your Study Room

Escape Your Study Room is my individual Mobile App Development project.

The app is a short student wellbeing exergame. Instead of keeping students inside the app for a long time, it gives them a short physical challenge and then encourages them to return to studying.

## Current focus

For the first portfolio submission I am developing one feature from start to finish:

**Dodge the Flying Books**

The student has to physically squat to dodge books flying through the study room. The feature will include the concept, user testing, development, movement detection and a final user test.
